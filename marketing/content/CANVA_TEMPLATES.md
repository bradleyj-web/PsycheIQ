## Quick Start
**URL**: https://www.canva.com (free account)

## Template 1: Starseed Result Card (Instagram Story Size)

### Step 1: Create Design
1. Click "Create a Design"
2. Select "Instagram Story" (1080 × 1920 px)
3. Or custom size: 1080 × 1920

### Step 2: Background
1. Click "Elements" → search "gradient"
2. Select "purple gradient" or create custom:
   - **Pleiadian**: Purple (#667eea) → Pink (#f093fb)
   - **Sirian**: Dark blue (#1e3c72) → Light blue (#00d2ff)
   - **Arcturian**: Teal (#11998e) → Green (#38ef7d)
   - **Andromedan**: Navy (#2c3e50) → Indigo (#6c5ce7)

### Step 3: Add Stars Effect
1. Elements → search "stars"
2. Add star graphics, set opacity to 30%
3. Or use "Texture" → "noise" at low opacity

### Step 4: Logo
1. Upload: `assets/psyche-hero.svg`
2. Resize to ~100px
3. Position top-right corner
4. Set opacity to 90%

### Step 5: Text Elements

| Element | Font | Size | Color | Position |
|---------|------|------|-------|----------|
| "COSMIC ORIGIN" | Montserrat Bold | 24px | White | Upper middle |
| Result Title (e.g., "Pleiadian") | Playfair Display Bold | 96px | White | Center |
| "Resonance" | Playfair Display Light | 72px | White | Below title |
| Origin subtitle | Montserrat Light | 32px | White | Below |
| "YOUR SOUL SIGNATURE" | Montserrat SemiBold | 28px | White | Traits box |
| Trait list | Montserrat Medium | 36px | White | In box |
| Summary quote | Playfair Display Italic | 28px | White/90% | Below traits |
| CTA text | Montserrat Regular | 24px | White/80% | Bottom |
| URL | Montserrat Bold | 40px | White | Bottom |

### Step 6: Traits Box
1. Elements → Shapes → Rounded Rectangle
2. Size: ~800px wide
3. Color: White at 10% opacity
4. Border: White at 20% opacity, 2px
5. Effects: Blur ~20px
6. Position: Center-bottom

### Step 7: Icons for Traits
1. Elements → search emoji or icons:
   - 💜 Heart (Pleiadian)
   - 🔵 Circle (Sirian)
   - 💚 Leaf (Arcturian)
   - 🔮 Crystal (Andromedan)
2. Size: 50px
3. Add circle background at 20% opacity

### Step 8: Export
1. File → Download → PNG
2. Transparent background: OFF
3. Quality: High

## Pro Tips

1. **Consistency**: Use same fonts across all designs
2. **Branding**: Logo always top-right or bottom-center
3. **Colors**: Stick to 3-4 colors per design
4. **Readability**: Text must be readable at thumbnail size
5. **Safe Zone**: Keep text away from edges (50px margin)
