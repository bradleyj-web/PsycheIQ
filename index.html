What this is

The Hermetic Nous pairs a reflective personality instrument with a set of cognitive puzzles, then reads them together. The language is Hermetic because that is the tradition the frame comes from: know the pattern, work the pattern, change the pattern.

Your answers stay in your browser for the length of the session. Nothing is sold on.

What this is not

The Pneuma Map is a mirror, not a diagnosis. It has no clinical validity and should never stand in for a conversation with a professional.

The Logos Matrix uses task families that resemble those in cognitive testing — matrix reasoning, mental rotation, digit span — but it is not a normed or supervised IQ test, and the tier you receive is a label inside this site, not a score you can carry elsewhere.
